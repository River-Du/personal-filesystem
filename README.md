# Personal Filesystem

一套可按需调整的个人文件夹分类模板，适用于电脑、NAS、移动硬盘、U 盘和网盘。

> 这套分类来自个人习惯，可自由取舍、改名或扩展，好用就行！

## 文件夹结构

`...` 表示可按需扩展的目录。

```text

personal-filesystem/
├── 00_Inbox/           # 收件箱，暂存未整理的文件
│
├── 01_Personal/        # 个人相关文件
│   ├── 00_Documents/   # 证件、证书等个人正式文件
│   ├── 01_Notes/       # 个人笔记、备忘、待办与计划
│   ├── 02_Vault/       # 需特别保管的文件，如密钥、API Key 等
│   └── .../            # 其他个人文件，如 Finance/、Health/ 等
│
├── 02_Projects/        # 参与的项目与创作文件，如工作项目、论文实验、视频剪辑等
│   ├── 00_Agents/      # AI Agent 工作空间
│   ├── 01_Archive/     # 已完成项目的归档
│   └── .../            # 其他项目，如 2026_Project/ 等
│
├── 03_Resources/       # 资源文件，如影视、音乐、游戏、书籍和素材等
│   ├── 00_Favorites/   # 特别收藏的资源
│   ├── 01_Local/       # 本设备专用资源，如壁纸、图标等
│   ├── 02_Olds/        # 不常用的旧资源
│   └── .../            # 其他分类或设备的资源，如 Movies/、Music/ 等
│
├── 04_Media/           # 个人记录的媒体文件
│   ├── 00_Photos/      # 照片
│   ├── 01_Videos/      # 视频
│   └── .../            # 其他分类、事件或设备的记录，如 2026_Beijing/ 等

```

## 如何使用

克隆仓库或下载 ZIP 并解压，将需要的目录复制到目标位置，再按习惯调整。

`.gitkeep` 用于让 Git 保留空目录。需要清理时，可运行根目录下的脚本，删除脚本所在目录及其子目录中的所有 `.gitkeep` 文件。

- Windows 可双击 `clean_gitkeep.bat`，或在 CMD 中运行 `clean_gitkeep.bat`。
- macOS / Linux 先运行 `chmod +x clean_gitkeep.sh`，再运行 `./clean_gitkeep.sh`。

## 使用建议

- 一级目录使用编号排序，子目录可按需添加编号
- More中的文件夹，如更常用可提至一级目录，或按需要调整顺序
- 文件和目录优先使用简洁、统一的英文名称，使用“_”作为连接符
- 重要文件建议在不同设备或介质上备份
- 定期整理文件，避免堆积过多未分类的内容
